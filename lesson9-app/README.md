# な형용사 학습 스튜디오

초급 학습자가 새로운 생활 표현과 일본어 な형용사의 어휘·활용을 단계적으로 익히는 정적 웹 앱입니다.

## 학습 내용

- `お久しぶりです・案内・商店街・におい・うなぎ・いっぱい・ごちそうさまでした・食べ物` 등 새 표현
- 겉모습을 보고 추량하는 `～そうです`의 의미와 접속법
- 주요 な형용사와 한국어 뜻
- 현재·과거 긍정형
- 현재·과거 부정형
  - `じゃありません / ではありません`
  - `じゃありませんでした / ではありませんでした`
- `な + 명사` 수식
- `好き・嫌い・上手・下手` 앞에 `を`가 아닌 조사 `が`가 오는 이유
- 무작위 선택형·블록 조립·문장 입력 연습

`index.html`을 브라우저에서 열면 바로 실행됩니다.
