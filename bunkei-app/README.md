# 문형 스튜디오

블록 조립과 히라가나 입력으로 일본어 기초 문형을 익히는 독립형 웹 앱입니다.

## 포함된 학습

1. `～は～です`: 의미, 조사 `は`의 `wa` 발음, 블록 조립
2. `～は～じゃありません`: 부정 표현, `じゃ`와 `では`의 관계
3. `～は～ですか`: 조사 `か`로 질문 만들기, `です`와 `か` 개별 블록 조립
4. `こ・そ・あ・ど`: 사물·장소·방향·명사 연결 표현
5. 한국어 문장과 일본어 문장 틀을 함께 제시하는 빈칸 어휘 입력
6. 단원마다 한 문제씩 일본어 문장 전체 입력
7. 기기에 설정된 일본어 입력기 사용
8. 모든 예문과 후보 한자의 후리가나

## 나선형 학습 흐름

`문형 알아보기 → 블록 조립 → 문장 속 빈칸 입력 → 문장 전체 입력` 순서로 앞 단계의 학습 내용을 누적합니다.

## 실행

`index.html`을 브라우저에서 열거나 VS Code의 Live Server로 실행합니다. 별도의 설치 과정은 필요하지 않습니다.
