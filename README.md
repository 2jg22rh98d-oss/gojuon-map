# 고주온 지도

오십음도표의 **위치·문자·소리**를 연결해 히라가나와 가타카나를 익히는 수업용 웹 앱입니다.

## 실행 방법

1. 이 폴더를 VS Code로 엽니다.
2. `index.html`을 브라우저에서 엽니다.
3. VS Code의 Live Server 확장 기능이 있다면 `index.html`에서 **Open with Live Server**를 선택하면 편리합니다.

별도의 설치나 빌드 명령은 필요하지 않습니다.

## 학습 단계

1. 완성된 오십음도표에서 빛나는 문자를 보며 발음 듣기
2. 발음만 듣고 올바른 위치 누르기
   - 현대 일본어에서 발음이 같은 `お`와 `を`는 각각 `あ행`, `わ행` 힌트 표시
   - 정답 후 획순 애니메이션을 보고 종이나 연습장에 직접 3번 쓰기
3. 문자 카드를 선택해 빈 오십음도의 올바른 위치에 놓기
4. 히라가나는 소리, 가타카나는 히라가나를 단서로 문자 카드와 위치 찾기

각 퀴즈는 10문제로 구성되며 학습 기록은 사용 중인 브라우저에 저장됩니다.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일을 저장소에 올립니다.
3. 저장소의 **Settings → Pages**에서 배포 원본을 `main` 브랜치의 `/ (root)`로 지정합니다.
4. 잠시 뒤 표시되는 웹 주소로 접속합니다.

## 수업 전 확인

- 사용하는 학교 태블릿이나 학생 휴대전화에서 일본어 음성이 재생되는지 확인하세요.
- 기기가 무음 모드인지 확인하세요.
- iPhone/iPad에서는 최초 한 번 화면을 눌러야 음성이 재생될 수 있습니다.
- 학습 기록은 기기와 브라우저별로 저장되며 교사에게 자동 전송되지 않습니다.

## 구성

- `index.html`: 화면 구조
- `styles.css`: 디자인 및 모바일 대응
- `app.js`: 오십음도 데이터, 음성, 퀴즈, 진도 저장
- `assets/audio`: 브라우저와 기기에 관계없이 재생되는 46개 문자 발음
- `assets/stroke-order`: 히라가나·가타카나 92자의 획순 애니메이션과 라이선스
