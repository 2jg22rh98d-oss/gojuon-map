# 문형복습 스튜디오

『みんなの日本語』 초급 1~3과의 학습 목표를 바탕으로 새롭게 구성한 복습용 웹 앱입니다. 원 교재의 사진과 문제를 복제하지 않고, 문형과 핵심 어휘를 이용해 독립적인 연습 문제로 재구성했습니다.

## 복습 흐름

`단어와 한국어 뜻 → 뜻 고르기 → 블록 조립하기 → 빈칸 채우기 → 문장 입력하기`

문장 입력하기는 단원마다 2문제이며, 한국어 문장만 보고 일본어 문장 전체를 입력합니다.

01~04 모든 과정은 넓은 문제 풀에서 접속할 때마다 일부를 무작위로 골라 순서도 바꾸어 출제합니다. 01~03은 뜻 고르기 4문제, 블록 4문제, 빈칸 3문제, 전체 문장 2문제이며, 04는 블록 11문제, 빈칸 7문제, 전체 문장 2문제입니다.

## 단원

1. 사람 소개: 국적, 직업, 나이, 긍정·부정·의문·も
2. 사물 확인: これ・それ・あれ, 何, 誰, 사물 어휘
3. 장소와 소속: ここ・そこ・あそこ・どこ, 시설, 나라, 회사, 대학
4. 문형복습하기: 핵심 어휘와 조사 설명, 1~3단원 혼합 블록 조립(긍정·부정 응답 포함), 문형 중심 빈칸 채우기, 문장 전체 입력
